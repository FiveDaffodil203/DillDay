# DillDay
Кроссплатформенный органайзер и планировщик DillDay для Windows, Linux и Android: календарь, будильники, задачи, привычки, дневник, важные даты, Pomodoro-таймер и темы оформления. Данные хранятся локально. ИИ-помощник Dill (распознавание расписаний из PDF и фото) и система аккаунтов пока в разработке.
